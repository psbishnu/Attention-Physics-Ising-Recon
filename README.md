# 🧠 Attention-Guided Physics-Informed Ising Reconstruction

A deep learning framework for inverse reconstruction of noisy 2D Ising spin configurations, combining attention mechanisms with physics-informed constraints.

## 🔍 Overview
Reconstruct clean Ising lattices from noisy or partially observed data while preserving thermodynamic properties like energy, magnetization, and correlation.

## 🧩 Key Features
- Attention-guided CNN
- Residual encoder–decoder
- Physics-informed loss functions
- Temperature & phase prediction
- Automated PDF reports
